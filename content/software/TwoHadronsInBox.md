summary: TwoHadronsInBox provides routines for performing finite volume analysis of two particles in a finite volume, relating the spectrum to the inverse K-matrix.
---

This software computes the quantization determinant involving the box matrix B and the Ktilde matrix which relates two-particle interaction energies in finite volume to the scattering matrix.  An overview of this software is given in the paper below:

